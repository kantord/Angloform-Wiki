# Attribution

Every article in `articles/` is a translation of a Wikipedia article into
Angloform. Wikipedia's text is licensed under the [Creative Commons
Attribution-ShareAlike 4.0 International License](https://creativecommons.org/licenses/by-sa/4.0/)
(CC BY-SA 4.0), dual-licensed with the GFDL. CC BY-SA 4.0 explicitly permits
adaptations — including translations — under these conditions, all of which
this project follows:

1. **Attribution.** Instead of listing every editor by name, each article
   links to the exact source revision; that page's history carries full
   author credit. This satisfies the license's attribution requirement
   without reproducing the editor list.
2. **Indicate changes.** Each article states that it is a translation and
   an adaptation — never presented as the original text.
3. **Same license, stated per copy.** Each article is itself released
   under CC BY-SA 4.0 (see `LICENSE`), with a link to the license text.
4. **No additional restrictions.** Nothing here adds terms (no NC, no ND)
   beyond what CC BY-SA 4.0 itself requires.

Not covered by this policy:
- **Images.** None are included yet. If added, each must be checked
  individually — Wikipedia media is usually hosted on Wikimedia Commons
  under its own (often different) license.
- **Quotations inside a source article** that Wikipedia itself uses under
  fair use rather than a free license are not carried into a translation.

## Attribution block template

Every file in `articles/` opens with this block before the translated
text:

```
> Translation of Wikipedia's "<Title>" article
> (<https://en.wikipedia.org/wiki/<Title>>), revision <oldid> (<date>):
> <https://en.wikipedia.org/w/index.php?title=<Title>&oldid=<oldid>>.
> This is an adapted translation into Angloform, not a literal rendering,
> and is not reviewed or endorsed by the original article's authors.
> Licensed CC BY-SA 4.0 — see ../LICENSE.
```
